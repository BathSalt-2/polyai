# 🧠 Polymathic Intelligence System

A hyper-intelligent synthetic cognitive system with PhD-level expertise across computer science, quantum physics, mathematics, psychology, music theory, and philosophy. Features comprehensive domain-specific knowledge databases and advanced research paper analysis capabilities for deep academic inquiry.

## ✨ Key Features

### 🤖 Cognitive Interface
- Advanced AI conversation system with multi-domain expertise
- Meta-cognitive reflection showing AI reasoning processes
- Persistent conversation history for continued discourse

### 📚 Expert Knowledge Database
- Comprehensive searchable database of PhD-level content
- 6 domains with hundreds of expert articles
- Academic level filtering (undergraduate → research)
- Cross-domain connection mapping

### 📄 Research Paper Analysis with PDF Upload
- **Upload PDF files directly** - drag & drop or click to upload
- Automatic text extraction and structure parsing
- AI-powered deep analysis of research papers
- Multi-paper comparison and synthesis
- Literature review generation
- Citation graph analysis
- Automated research question generation

### 🔬 Advanced Analysis Tools
- Compare papers to identify relationships and contradictions
- Build citation graphs and identify central papers
- Suggest optimal reading orders
- Generate comprehensive research questions
- Identify research gaps and future directions

### 📱 Mobile-Optimized Experience
- Touch-responsive interface
- Swipe gestures for tab navigation
- Adaptive layouts for all screen sizes
- Bottom sheets for mobile domain selection

## 🎯 How to Use PDF Upload

1. Navigate to the **Research Papers** tab
2. Choose **Upload PDF** (default)
3. Either:
   - Click "Select PDF File" to browse
   - Drag and drop a PDF file onto the upload area
4. Wait for AI-powered text extraction and parsing
5. Review and edit the extracted information
6. Click "Add to Library"
7. Analyze papers individually or compare multiple papers

### Supported Formats
- PDF files with text layers (most academic papers)
- AI-powered extraction works even with complex formatting
- Automatic structure detection (title, authors, abstract, content)

## 🛠 Technology Stack

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS + Shadcn UI
- **AI**: OpenAI GPT-4o integration
- **Persistence**: Spark KV storage
- **PDF Processing**: Custom text extraction + AI parsing
- **Icons**: Phosphor Icons
- **Animations**: Framer Motion
